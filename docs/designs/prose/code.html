Getting Started

Deslop is an ultra-fast, high-precision CLI tool for identifying and eliminating duplicate code across massive codebases. Built on Rust for performance and accuracy.

download Installation

macOS / Linux (Homebrew) 
brew install melbournedeveloper/tap/deslop
NPM / Yarn (Node.js wrapper) 
scoop install deslop

bolt Quick Start

To analyze your current directory recursively, simply run the primary command. By default, it uses a conservative threshold to ensure high accuracy.

Terminal
$ deslop .
[INFO] Scanning 14,203 files...
[INFO] Hashing AST nodes...
[INFO] Identifying duplications...
Analysis Complete (0.042s)
Found 12 duplication clusters saving potential 4.2MB.

analytics Visual Reporting

The CLI can generate interactive HTML reports detailing exact file matches, AST similarities, and suggested refactoring paths.

tune Threshold Tuning

Adjust the sensitivity of the detection engine. Lower values catch smaller, potentially coincidental matches, while higher values ensure strict structural identicality.

--threshold=strict
Confidence: >98%

Requires exact AST structural matches and similar variable naming conventions.

--threshold=balanced (Default)
Confidence: >85%

Ignores variable names and pure literal changes. Focuses on structural flow.

--threshold=loose
Confidence: >60%

Aggressive matching. May flag design patterns or necessary boilerplate as duplicates.
