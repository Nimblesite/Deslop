## Pairs only jscpd reports

jscpd reported 8666 pairs. Deslop's report shows no cluster overlapping both ranges for 3507 of them (40.5%). None of these pairs has been judged, so they are neither counted as Deslop misses nor as jscpd false positives.

## Caveat: whose candidates were judged

The registers were built by judging candidate pairs drawn from Deslop's own reports (two Deslop versions side by side), so every judged pair is one some Deslop build proposed. Recall here measures how many of those real duplicates each tool finds; pairs only jscpd reports were never judged, so neither tool's precision outside the register is measured, and the 8 CLEARLY OUT entries are too few to rank precision. A fair precision comparison needs a judging pass over a sample of jscpd's own pairs.
