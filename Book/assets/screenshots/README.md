# Actual UI captures

These images come from the running Deslop extension in VS Code, analysing the Deslop repository. Masters retain the original screenshot bytes as JPEG files. Publication PNGs only crop and uniformly resize them; no product pixels or text are repainted.

- `04-cluster-panel.png`: actual Identical code group, occurrences, and comparison controls.
- `10-compare-to-canonical.png`: actual side-by-side comparison of two test setup ranges.
- `08-report-overview.png`: the actual Duplication sidebar, cropped from the cluster capture.

`figures.json` records crop rectangles, dimensions, hashes, captions, and the environment reference in `book.json`. These captures show findings, not a completed refactor or accuracy benchmark.
