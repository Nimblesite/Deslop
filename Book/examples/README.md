# Workshop examples

The finished book will include a small, tested Workshop repository that accumulates duplication in controlled stages and then removes it behind empirical gates.

The scaffold deliberately does not commit duplicated sample implementations yet. Each example checkpoint must be generated or authored with its chapter, run through the pinned Deslop release, and accompanied by before/after report artifacts and native test results.

Planned checkpoints:

- `prevent/` — a proposed helper is stopped by `find-similar`
- `live-loop/` — editor and MCP observe the same working-set change
- `baseline/` — read-only audit artifacts with provenance
- `actionability/` — one justified consolidation and one retained duplicate group
- `cleanup/` — passing tests, surgical consolidation, rescan, and ceiling ratchet
